本书是 Josh Hug 版本的 UC Berkeley 数据结构课程 CS61B 的配套读物。课程 2021 年春季版本位于 [https://sp21.datastructur.es/](https://sp21.datastructur.es/)。此后可能已有更新版本，请参阅 [https://datastructur.es](https://datastructur.es)。

本课程默认你已经牢固掌握编程基础。至少应熟悉面向对象编程、递归、列表和树等概念，也应当会在自己使用的操作系统中操作终端。如果你还没有这些经验，建议先学习 UC Berkeley 的编程入门课程 [CS61A](http://cs61a.org/)。

如果你已经有 Java 经验，可以考虑直接从第 2 章开始；不过快速浏览第 1 章仍可能有所收获。
