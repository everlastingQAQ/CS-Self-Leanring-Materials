# Project 2 Checkpoint

- 原截止时间：2021-03-12
- 性质：Gitlet 提前检查点；当年提供额外分
- 关联规格：Project 2: Gitlet

> **文档性质**：本文件依据 CS 61B Spring 2021 官方页面，由 ChatGPT 独立阅读后制作中文学习版。  
> 为保留技术准确性，类名、方法名、文件名、命令、报错文本和 API 名称保持英文。本文采用逐节翻译与重述，而不是网页的逐句镜像。

## 检查点目标

鼓励在最终截止前三周完成 Gitlet 的基础版本，而不是把所有工作拖到 merge 周。

## 建议达到的状态

至少稳定完成：

- `init`
- `add`
- `commit`
- `rm`
- `log`
- `global-log`
- `find`
- `status`

同时应具备：

- 清晰的 `.gitlet` 目录结构。
- Commit 与 Blob 的持久化。
- Staging Area。
- 基础集成测试。
- 已更新的 Design Document。

## 检查点之后

立即进入 checkout、branch、reset 和 merge。不要因为通过 checkpoint 就暂停项目。
