## 当周目标

集中推进 Project 2 Gitlet，并为 Midterm 2 做准备。建议工作顺序：

1. 确认基础命令 `init`、`add`、`commit`、`rm`、`log` 已稳定。
2. 完成 branch、checkout、reset。
3. 为每条命令编写 `.in` 集成测试。
4. 使用 staff solution 验证测试预期。
5. 用 `runner.py` 或 tester 的 `--keep` 保留失败现场。
6. 更新 Design Document，使其与当前实现一致。
7. 不要在 merge 尚未设计清楚时仓促堆代码。

## 工作日结束标准

至少应有一套可重复运行的本地测试，并能通过命令行完整演示一次基本版本控制流程。
