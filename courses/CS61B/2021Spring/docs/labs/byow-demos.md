## BYOW Demo 目标

展示项目中最能代表设计与工程工作的部分，而不是只运行默认流程。

建议演示：

- 相同 seed 生成相同世界。
- 不同 seed 生成明显不同世界。
- 新建、移动、保存、退出、加载。
- HUD。
- 一项或多项 ambition feature。
- 错误输入的处理。
- 游戏的视觉或交互特色。

## 展示前检查

- 从全新进程启动。
- 清理旧存档后测试新建。
- 准备一个确定可演示的 seed。
- 避免演示依赖偶然随机结果。
- 保证运行命令和 Working Directory 正确。
