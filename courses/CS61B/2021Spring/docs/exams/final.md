## 考试范围

综合覆盖整学期，重点包括：

- Java、引用、继承、多态、Iterator
- Deque 与实现权衡
- 测试、调试、Git 与软件工程
- 渐进复杂度和均摊分析
- Union-Find
- BST、B-Tree、LLRB、Hashing
- Heap、Priority Queue
- 图遍历
- Dijkstra、Prim、Kruskal
- Trie 与 range searching
- 排序、稳定性和下界
- Compression 与复杂性课程结尾内容
- 大型项目中的设计和持久化思想

课程说明某些软件工程讲座不要求专门复习，但考试原则上可结合已覆盖内容进行综合考察。

## 当年考试规则

- PrairieLearn。
- Zoom 监考/录制。
- 手写笔记不限数量。
- 草稿纸可用。
- 禁止运行代码环境、网络搜索、计算器和未授权设备。
- 必须提交考后表单并报告录制异常。

## 最终复习路线

1. 用一张表串联每种数据结构的 API、内部表示、复杂度与不变量。
2. 手算算法中间状态。
3. 完成历年综合题并限时。
4. 把错题按“概念、建模、执行、格式、时间”分类。
5. 重做错题，直到不看答案能完整解释。
6. 整理手写笔记时优先写易混边界和解题步骤，不抄整页定义。
