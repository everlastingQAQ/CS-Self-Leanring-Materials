# Midterm 1 Practice Assessment

- 课程日历：原截止时间 2021-02-07
- 性质：期中一模拟评估；课程日历没有公开独立规格页

> **文档性质**：本文件依据 CS 61B Spring 2021 官方页面，由 ChatGPT 独立阅读后制作中文学习版。  
> 为保留技术准确性，类名、方法名、文件名、命令、报错文本和 API 名称保持英文。本文采用逐节翻译与重述，而不是网页的逐句镜像。

## 练习目的

提前验证：

- PrairieLearn 类考试平台是否正常。
- 远程监考与录制流程是否可行。
- 手写笔记和草稿纸安排。
- 对考试题型和作答节奏的熟悉程度。

## 建议覆盖范围

根据 Midterm 1 前课程进度，重点包括：

- Java 基础、类与对象
- 引用、递归、链表
- SLList、DLList、数组、AList
- 测试与调试
- 继承、接口、动态方法选择
- 类型转换与高阶函数
- 基础迭代器与多态

## 完成方式

严格按正式考试环境完成一次，不查额外资料，并记录：

- 哪些题是知识不会。
- 哪些题是读题失误。
- 哪些题是时间不够。
- 哪些 Java 细节容易混淆。
