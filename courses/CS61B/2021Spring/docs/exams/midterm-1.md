# Midterm 1

- 原考试时间：2021-02-10，20:00–22:00（加州时间）
- 原课程分值：1280 points
- 参考页面：课程主页、About 与 Exam Proctoring Guide

> **文档性质**：本文件依据 CS 61B Spring 2021 官方页面，由 ChatGPT 独立阅读后制作中文学习版。  
> 为保留技术准确性，类名、方法名、文件名、命令、报错文本和 API 名称保持英文。本文采用逐节翻译与重述，而不是网页的逐句镜像。

## 考试范围概览

考试位于 Lecture 10 后，主要覆盖：

- Java 执行模型、作用域、static
- 引用与 pass-by-value
- 递归与链表
- 数组与动态数组
- 接口、继承、多态
- casting
- 测试与调试
- 基础迭代/对象方法的前置内容

## 当年考试规则

- 使用 PrairieLearn。
- 通过 Zoom 远程监考和录制。
- 可使用不限数量的手写笔记。
- 可使用草稿纸。
- 不允许搜索网页、运行 IntelliJ、使用计算器或其他未列出的设备/软件。
- 必须严格遵循录制和考后表单要求。

这些规则属于 2021 年课程安排，自学者不需要复刻监考流程，但可以保留闭卷限时模拟。

## 复习方法

1. 自己画盒指针图。
2. 手算代码执行结果。
3. 比较 compile-time type 与 runtime type。
4. 写出递归调用栈。
5. 做 exam-prep discussion，而不是只重看讲座。
6. 完成后按错误类型复盘。
