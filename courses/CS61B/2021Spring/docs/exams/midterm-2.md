## 考试范围概览

考试位于 Lecture 24 前后，重点从 Java 结构设计扩展到算法与树：

- Exceptions、Iterator、Object methods
- Git 与命令行基础
- 渐进复杂度
- Disjoint Sets
- ADT、Set、Map
- BST、B-Tree、LLRB
- Hashing
- Heap 与 Priority Queue
- 树和图遍历
- 最短路的基础内容
- Project 2 规格理解与软件设计能力

## 复习重点

- 手算循环与递归复杂度。
- 从 WQU 数组还原树。
- 在 2-3 tree 与 LLRB 之间转换。
- 判断哈希表扩容与冲突。
- 写 BFS/DFS 访问顺序。
- 理解 heap 数组索引。
- 分清图遍历中的 fringe、visited、edgeTo。
- 通过 HW2 和 exam-prep discussion 检查概念漏洞。

## 当年考试规则

与 Midterm 1 类似，使用远程监考、PrairieLearn 和手写笔记。自学时建议限时完成综合题，并在结束后重做所有错题。
